## 1. 产品概述

### 1.1 产品定位

**LabelKit** 是一款面向算法工程师与标注团队的 **本地 YOLO 标注训练平台**，运行在用户本机（浏览器 + 本地后端），以**项目**为单位隔离数据与模型。

核心价值主张：

> 从原始视频/图片出发，经抽帧去重 → AI 自动标注 → 人工复查 → 训练/导出 YOLO 模型，形成可闭环迭代的标注工作流。

### 1.2 产品形态

| 维度 | 说明 |
|------|------|
| 部署方式 | 本地运行：Next.js 前端 `:3000` + FastAPI 后端 `:8010` |
| 数据存储 | SQLite 元数据 + `data/projects/<id>/` 本地文件 |
| 用户模式 | 单用户本地工具，**无登录/多租户** |
| AI 能力 | LLM 视觉大模型（DashScope）+ YOLO `.pt` 模型 |
| 任务类型 | 目标检测（detect）、图像分类（classify） |

### 1.3 目标用户

| 角色 | 典型诉求 |
|------|----------|
| 算法工程师 | 快速从监控视频/图片构建训练集，迭代 YOLO 模型 |
| 标注质检员 | 高效复查 AI 标注结果，手动画框修正 |
| 项目负责人 | 掌握各项目进度、素材规模、任务状态 |

### 1.4 核心使用场景

1. **从零建库**：上传产线/安防视频 → 抽帧 → LLM 打框 → 人工确认 → 训练导出  
2. **已有数据迁移**：导入 YOLO 格式数据集，直接进入复查/训练  
3. **模型反哺**：训练或上传 `.pt` 后，对驳回/未标注图片半自动重标  
4. **难例闭环**：复查驳回 → YOLO/LLM 重标 → 再确认 → 再训练

## 3. 核心业务流程

### 3.1 主流程（目标检测）

```mermaid
flowchart LR
    A[创建项目] --> B[上传视频/图片]
    B --> C[抽帧 + 去重]
    C --> D[自动标注]
    D --> E[机器预审 可选]
    E --> F[人工复查]
    F --> G[训练 / 导出]
    G --> H[模型反哺重标]
    H --> F
```

### 3.2 各阶段用户目标

| 阶段 | 用户想完成什么 | 成功标准 |
|------|----------------|----------|
| 建项目 | 定义任务类型与检测类别 | 项目创建成功，类别已配置 |
| 素材 | 把原始媒体变成可标注图片帧 | 帧入库，状态为「未标注」 |
| 标注 | 批量获得初始框 | 未标注帧减少，产生待确认/已标状态 |
| 复查 | 确认或修正每一张 | 待确认归零，已确认可用于训练 |
| 训练 | 产出可用模型或数据集 | 训练完成 / 导出目录可用 |
| 反哺 | 用模型修正难例 | 驳回帧被重标，进入复查 |

### 3.3 两条标注路径

用户可在「自动标注」和「复查」中选择不同引擎：

| 引擎 | 适用 | 成本 | 速度 |
|------|------|------|------|
| **LLM 大模型** | 冷启动、无模型、难例 | 按张计费（可预估） | 较慢 |
| **YOLO .pt 模型** | 已有模型、批量重标 | 本地免费 | 快 |

## 4. 核心数据实体

设计师需理解以下实体及其在界面上的呈现关系。

### 4.1 项目（Project）

| 字段 | 含义 | 展示场景 |
|------|------|----------|
| `name` | 项目名称 | 列表、概览、面包屑 |
| `description` | 描述 | 列表、概览 |
| `task_type` | `detect` / `classify` | 标签：目标检测 / 图像分类 |
| `categories[]` | 检测类别（名称、描述、颜色、是否必选） | 建项、设置、标注编辑器 |
| `frame_count` | 帧总数 | 列表、概览 |
| `video_count` | 视频数 | 列表 |
| `disk_usage_mb` | 磁盘占用 | 列表、存储统计 |
| `label_prompt` / `review_prompt` | LLM 提示词 | 项目设置 |
| `created_at` / `updated_at` | 时间 | 列表排序、活动流 |

### 4.2 视频（Video）

| 字段 | 含义 | 展示场景 |
|------|------|----------|
| `filename` | 文件名 | 素材页列表 |
| `duration_sec` | 时长 | 抽帧预估 |
| `frame_count` | 原片总帧数 | 素材页 |
| `extracted_count` | 已提取张数 | 素材页、勾选状态 |

### 4.3 图片帧（Frame）

每张可标注图片，核心工作台对象。

| 字段 | 含义 |
|------|------|
| `filename` | 文件名 |
| `status` | 标注流程状态（见 §6） |
| `annotations[]` | 标注框列表（class_id, 归一化坐标, 置信度） |
| `split` | train / val |
| `uncertainty` | 不确定性分数（排序用） |
| `source` | 来源（抽帧、上传、导入等） |
| `video_id` | 关联视频 |

### 4.4 模型版本（ModelVersion）

| 字段 | 含义 |
|------|------|
| `version` | 版本号 v1, v2… |
| `name` | 显示名称 |
| `metrics` | 训练指标 / 来源标记 |
| `filepath` | 本地 `.pt` 路径 |

### 4.5 后台任务（Task）

| 字段 | 含义 |
|------|------|
| `task_type` | 任务类型（见 §7） |
| `status` | pending / running / completed / failed / cancelled |
| `progress` / `total` | 进度 |
| `params` | 启动参数 |
| `result` | 结构化结果 |
| `log` | 文本日志 |
| `error` | 失败原因 |

## 6. 帧状态体系

设计师需将**内部状态**映射为**用户可理解的简化状态**。

### 6.1 状态流转

```
未标注 (unlabeled)
    ↓ LLM/YOLO 标注
LLM已标 (llm_labeled) / 机器通过 (auto_ok) / 机器存疑 (needs_human) / 已自动修复 (auto_fixed)
    ↓ 人工复查
人工确认 (human_ok) / 无目标 (no_target) / 已驳回 (human_wrong)
    ↓
参与训练 & 导出
```

### 6.2 用户看到的简化状态

| 简化状态 | 包含的内部状态 | 用户理解 |
|----------|----------------|----------|
| 未标注 | unlabeled | 还没打框 |
| 待确认 | llm_labeled, auto_ok, needs_human, auto_fixed | 机器已标，等我确认 |
| 已确认 | human_ok, no_target | 可用于训练 |
| 已驳回 | human_wrong | 我点了 N，需要改或重标 |

### 6.3 项目概览「素材进度」五格

| 指标 | 含义 |
|------|------|
| 总素材 | 已入库图片帧总数 |
| 未标注 | 等待自动标注 |
| 待确认 | 等待人工复查 |
| 已确认 | 复查通过 |
| 已驳回 | 复查驳回 |

支持「展开详情」查看各内部状态明细。

## 7. 后台任务体系

### 7.1 任务类型一览

| 类型 | 中文名 | 触发页面 | 说明 |
|------|--------|----------|------|
| `extract` | 提取素材 | 素材管理 | 视频抽帧 + 可选去重 |
| `dedup` | 素材去重 | 素材管理 | 单独去重（通常与 extract 合并） |
| `label` | 自动标注 | 自动标注 | LLM 批量打框 |
| `review` | 自动审查 | 复查标注 | LLM 机器预审 |
| `relabel` | YOLO 半自动 | 标注/复查/模型库 | 用 .pt 模型重标 |
| `train` | 训练模型 | 训练模型 | YOLOv8 微调 |
| `export` | 导出数据 | 训练模型 | 导出 YOLO 目录结构 |
| `import` | 导入数据 | 项目设置 | 导入已有 YOLO 数据集 |
| `derive_classify` | 生成分类集 | 项目设置 | 从检测框裁剪生成分类素材 |

### 7.2 任务通用交互

| 交互 | 说明 |
|------|------|
| 启动任务 | 按钮触发，参数随任务类型变化 |
| 进度轮询 | 前端定时刷新进度（2–5 秒） |
| 停止任务 | 运行中可取消，当前张处理完后终止 |
| 完成通知 | 页面内 banner / 状态变化 |
| 失败展示 | 错误信息区域 |

### 7.3 各任务结果摘要（任务详情用）

| 任务类型 | 结果展示 |
|----------|----------|
| 导出 | 训练集/验证集/合计数量 + 打开文件夹 |
| 提取/去重 | 抽出帧数、保留数、删除数 |
| 标注/重标 | 成功/失败张数、标注范围 |
| 训练 | 模型版本、数据集规模、模型路径 |
| 审查 | 机器通过张数 |

## 8. 项目内功能模块（按页面）

### 8.1 项目概览（`/projects/{id}`）

**页面目标**：项目仪表盘，展示进度并分发到各子模块。

#### 内容区块

| 区块 | 内容 |
|------|------|
| 项目头图 | 名称、描述、任务类型、帧数、磁盘、类别标签 |
| 模型入口 | 链接至模型库（带 project 参数） |
| 删除项目 | 危险操作，二次确认 |
| 素材进度 | 五格统计 + 可展开详情 |
| 功能入口卡片 | 素材管理、自动标注、复查标注、训练模型、项目设置 |

#### 功能卡片信息

每张卡片：标题 + 一行说明 + 点击进入对应页面。

---

### 8.2 素材管理（`/projects/{id}/materials`）

**页面目标**：接入原始媒体，产出可标注图片帧。

#### 功能清单

| 功能 | 说明 |
|------|------|
| 上传视频 | 多选，支持 mp4/avi/mov/mkv |
| 直接上传图片 | 跳过抽帧，直接进入标注流程 |
| 视频列表 | 展示时长、原片帧数、已提取张数 |
| 按视频勾选 | 仅处理选中视频；新上传默认选中 |
| 快捷选择 | 「仅选未提取」「全选」 |
| 抽帧参数 | 每秒抽几帧（fps）、最多保留张数、去重严格度 |
| 动态预估 | 根据选中视频时长 × fps 实时显示预计张数 |
| LLM 建议保留张数 | 调用建议接口填充上限 |
| 开始提取 | 启动 extract 任务（含自动去重） |
| 素材就绪提示 | 有帧时显示总数，引导「下一步：自动标注」 |
| 最近任务 | 展示最近提取/去重任务状态 |

#### 关键交互

- 重新提取会先清除该视频旧帧再抽（覆盖式）
- 提取为后台任务，页面轮询进度

---

### 8.3 自动标注（`/projects/{id}/label`）

**页面目标**：对 **未标注** 图片做首轮批量打标（仅此职责，不含重标）。

#### 功能清单

| 功能 | 说明 |
|------|------|
| 模式切换 | YOLO .pt 模型 / LLM 大模型 |
| 未标注统计 | 当前待处理张数 |
| LLM 费用预估 | 待标张数 × 单价 = 预估费用 |
| 开始标注 | LLM：启动 label 任务；YOLO：对未标注启动 relabel |
| 停止标注 | 取消运行中任务 |
| 进度展示 | 单条进度条 + 已处理数量 |
| 标注结果列表 | 滚动展示所有已处理帧 |
| 结果缩略图 | 点击预览，双击跳转人工确认页 |
| 进入人工确认 | 引导链接 |

> **不负责**：对已驳回/待确认图片重标；手动画框修正一律在人工确认页。

---

### 8.4 人工确认（`/projects/{id}/review`）

**页面目标**：逐张验收机器标注，产出「已确认」数据。

> **这是全产品交互密度最高的页面。**

#### 页面结构（逻辑分区）

1. **筛选 Tab**（待确认 / 已驳回 / 已确认 / 全部）
2. **主工作区**（大图 + 标注编辑器 + 缩略图导航）
3. **驳回修正**（仅「已驳回」Tab 显示，YOLO/LLM 批量修正）
4. **机器预审**（可选，默认折叠）

#### 驳回修正（仅已驳回）

| 功能 | 说明 |
|------|------|
| 显示条件 | 仅在「已驳回」筛选 Tab 下出现 |
| 引擎切换 | YOLO .pt（默认）/ LLM 难例 |
| 固定范围 | 仅 `human_wrong`，不可选未标注/待确认 |
| 启动 / 停止 | relabel 或 label 任务 |

#### 机器预审（可选，默认折叠）

| 功能 | 说明 |
|------|------|
| 开始自动审查 | LLM 批量检查标注质量 |
| 停止审查 | 取消运行中任务 |
| 审查进度 | 进度条 |
| 完成提示 | Banner：「机器预审完成 N 张，已归入待确认」 |

#### 筛选 Tab

| Tab | 数量角标 | 含义 |
|-----|----------|------|
| 待确认 | 实时统计 | 机器已标，待人工 Y/N |
| 已驳回 | 实时统计 | 点了 N 的图 |
| 已确认 | 实时统计 | 可用于训练 |
| 全部 | — | 所有已标注图 |

Tab 切换时支持 URL 参数 `?filter=` 和 `?frame=` 深链接。

#### 标注编辑器（目标检测）

| 功能 | 说明 |
|------|------|
| 画布展示 | 图片 + 标注框叠加 |
| 画新框 | 鼠标拖拽 |
| 选中/移动框 | 点击选中，拖拽移动 |
| 删除框 | 快捷键或按钮 |
| 类别选择 | 切换当前绘制类别 |
| 确认 (Y) | 保存并标记 human_ok，自动跳下一张 |
| 驳回 (N) | 标记 human_wrong |
| 无目标 | 标记 no_target（空标注） |
| 未保存提示 | 切换图片/筛选时若有修改需确认 |
| 键盘快捷键 | Y 确认、N 驳回等 |

#### 导航

- 上一张 / 下一张
- 缩略图条或列表跳帧
- 当前序号 `n / total`

#### 状态引导 Banner

- 待确认清零 → 提示可开始训练
- 有待确认时提示继续人工确认
- 有驳回时提示使用驳回修正

---

### 8.5 训练模型（`/projects/{id}/train`）

**页面目标**：用已确认数据训练 YOLO，或导出标准数据集。

#### 数据集概况

| 信息 | 说明 |
|------|------|
| 可训练样本数 | auto_ok + auto_fixed + human_ok + no_target |
| 人工确认数 | human_ok + no_target |
| 验证集比例 | 滑块/输入，默认 20% |
| 预估划分 | 动态显示训练 N / 验证 M |

#### 训练参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 训练轮数 (epochs) | 80 | |
| 输入尺寸 (imgsz) | 640 | |
| 批次大小 (batch) | 8 | |
| 计算设备 | mps/cuda/cpu | Mac 用 MPS，NVIDIA 用 CUDA |
| 基座模型 | yolov8s.pt | 预训练权重 |

#### 训练操作

- 开始训练 → 后台 train 任务
- 训练进度与日志（运行中任务）
- 模型版本列表（最近版本，链接模型库）

#### 导出数据集

| 功能 | 说明 |
|------|------|
| 导出目录 | 文本输入 + 系统文件夹选择器 |
| 目录命名 | 默认 `{项目名}-dataset` 子目录 |
| 验证集比例 | 与训练共用 |
| 开始导出 | 后台 export 任务 |
| 导出完成 | 显示训练/验证张数 + 打开文件夹 |
| 覆盖确认 | 目录已有文件时二次确认 |
| 记忆路径 | localStorage 记住上次目录 |

导出格式：标准 YOLO 目录（images/train、images/val、labels/…）。

### 8.6 项目设置（`/projects/{id}/settings`）

**页面目标**：项目级配置与数据迁移。

#### 功能区块

| 区块 | 内容 |
|------|------|
| 提示词 | 标注提示词、审查提示词（多行文本） |
| 类别定义 | 编辑类别名称与 LLM 描述 |
| 保存设置 | 提交更新 |

## 9. 关键交互模式汇总

设计师应统一考虑以下跨页面交互模式：

| 模式 | 出现场景 | 期望体验 |
|------|----------|----------|
| 后台长任务 | 提取、标注、训练、导出 | 可离开页面，任务中心可追踪 |
| 轮询刷新 | 多数项目页 | 运行中快刷，空闲慢刷 |
| 流程引导 | 素材→标注→复查→训练 | 每步完成有明确「下一步」 |
| 双引擎切换 | 标注、复查重标 | YOLO/LLM Tab 清晰区分成本与速度 |
| 图片 Lightbox | 任务中心标注概况 | 大图 + 左右翻页 + Esc 关闭 |
| 深链接 | 复查页 | URL 带 filter 和 frame 参数 |
| 危险操作 | 删除项目、覆盖导出 | 必须二次确认 |
| 本地路径 | 导入、导出 | 本机绝对路径；文件夹用系统选择器 |
| 打开文件夹 | 导出完成 | 通用文案，非平台特定名称 |

## 10. 当前产品体验问题（设计改进方向）

> 以下为用户与产品方对**现版 UI** 的共识痛点，供重设计时重点突破。  
> **不代表要删减功能**，而是信息架构与视觉层级需要升级。

| 问题 | 表现 | 设计方向建议 |
|------|------|--------------|
| Demo 感强 | 卡片堆叠、说明文字过多、缺少专业工作台气质 | 建立「精密数据工作台」视觉语言，强化层级与留白节奏 |
| 流程感弱 | 四步导航像 Tab，缺少「当前在哪、下一步是什么」 | 强化流程进度与阶段完成状态 |
| 信息重复 | 同类统计在概览、子页、任务详情多处出现 | 明确每页「主信息」与「辅助信息」分工 |
| 复查页过重 | 机器预审、重标、筛选、编辑挤在一页 | 考虑分区、折叠或可切换工作模式 |
| 任务与页面割裂 | 后台任务在任务中心，操作在业务页 | 业务页内嵌轻量任务状态，任务中心做深度查看 |
| 路径/技术字段外露 | 绝对路径、内部状态码 | 默认隐藏技术细节，按需展开 |
| 首页过重 | 三栏 dashboard 信息密度高 | 区分「日常入口」与「运营监控」层级 |
| 缺少空状态/引导 | 部分页面 0 数据时引导不足 | 每步空状态配明确下一步操作 |

## 11. 非功能需求（影响设计）

| 维度 | 要求 |
|------|------|
| 性能 | 单项目可达数百～数千帧，缩略图列表需虚拟滚动或分页 |
| 长时间使用 | 复查页用户可能连续操作数小时，需低视觉疲劳 |
| 本地环境 | 无需登录；API Key 本地存储 |
| 响应式 | 主要面向桌面宽屏（≥1280px），复查页最低宽度需保证画布可用 |
| 无障碍 | 关键操作除鼠标外支持键盘（复查 Y/N、Lightbox 方向键） |
| 中文优先 | 所有用户可见文案为中文 |
