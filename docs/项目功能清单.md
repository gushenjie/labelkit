# LabelKit 项目功能清单

> 本清单根据当前代码与页面功能整理，适用于方案说明、验收范围梳理和后续需求拆分。

## 1. 项目生产台

| 功能项 | 功能说明 | 当前状态 |
| --- | --- | --- |
| 项目列表 | 展示全部标注项目，统计项目数、数据帧数、待复查数量、运行任务数、存储占用等概览信息。 | 已实现 |
| 项目检索与筛选 | 支持按项目名称/描述搜索，按目标检测、图像分类筛选，并按最近更新、名称、数据量排序。 | 已实现 |
| 新建项目 | 支持创建目标检测或图像分类项目，填写项目名称、描述、类别名称和类别视觉描述。 | 已实现 |
| 项目删除 | 支持删除项目及其关联素材、标注、任务和模型文件。 | 已实现 |
| 项目工作台 | 以项目为单位展示素材准备、智能标注、人工复查、训练导出四阶段流程。 | 已实现 |
| 下一步引导 | 根据素材、标注、复查和训练状态自动推荐下一步操作。 | 已实现 |

## 2. 素材管理

| 功能项 | 功能说明 | 当前状态 |
| --- | --- | --- |
| 本地视频上传 | 支持批量上传 MP4、MOV、AVI 等视频文件，并保留原始素材信息。 | 已实现 |
| 本地图片上传 | 支持批量上传 JPG、PNG、WEBP 等图片，作为可标注数据帧入库。 | 已实现 |
| 拖拽上传 | 支持将视频或图片拖拽到页面进行上传。 | 已实现 |
| 上传队列 | 展示批量上传进度、完成数量和单文件状态。 | 已实现 |
| 视频清单 | 展示已上传视频的文件名、时长、原片帧数、已提取帧数。 | 已实现 |
| 视频抽帧 | 支持选择视频后按指定 FPS 抽取训练帧。 | 已实现 |
| 抽帧数量控制 | 支持设置最多保留帧数，0 表示不限制。 | 已实现 |
| 相似帧去重 | 基于 phash 对抽帧结果进行相似图片去重，减少重复标注。 | 已实现 |
| 去重严格度配置 | 支持配置去重阈值，控制相似画面的保留力度。 | 已实现 |
| 公开数据检索方案 | 可输入自然语言需求，生成公开数据集检索方案和筛选维度。 | 能力预览 |
| 公开数据源导入 | 预留 Roboflow、Kaggle 等公开数据源接入与一键导入能力。 | 规划中 |

## 3. 自动标注

| 功能项 | 功能说明 | 当前状态 |
| --- | --- | --- |
| LLM 自动标注 | 调用视觉大模型对未标注图片生成初始标注结果。 | 已实现 |
| YOLO 半自动标注 | 使用已上传或已训练的 YOLO `.pt` 模型对图片进行批量标注。 | 已实现 |
| 标注引擎切换 | 支持在 LLM 大模型和 YOLO `.pt` 模型之间切换。 | 已实现 |
| 费用预估 | 根据待标注图片数量和单张成本估算 LLM 标注费用。 | 已实现 |
| 标注任务进度 | 展示自动标注任务进度，支持停止运行中的任务。 | 已实现 |
| 最近标注结果 | 展示最近生成的标注结果，可双击进入人工复查。 | 已实现 |
| 驳回样本重标 | 对人工驳回的样本支持再次使用 LLM 或 YOLO 修正标注。 | 已实现 |

## 4. 人工复查与标注编辑

| 功能项 | 功能说明 | 当前状态 |
| --- | --- | --- |
| 待确认队列 | 按待确认、已驳回、已确认、全部等维度筛选标注图片。 | 已实现 |
| 图片逐张复查 | 支持逐张查看机器标注结果和当前帧状态。 | 已实现 |
| 快捷键操作 | 支持 Y 确认、N 驳回、0 无目标、方向键翻页、Del 删除框。 | 已实现 |
| 手动画框/改框 | 支持在图片上新增、修改、删除目标检测框。 | 已实现 |
| 分类结果确认 | 图像分类项目支持整图类别确认与修正。 | 已实现 |
| 无目标标记 | 支持将图片标记为无目标，使其可进入训练/导出流程。 | 已实现 |
| 机器预审 | 对机器标注结果进行自动审查，将风险样本推入人工复核。 | 已实现 |
| 复查统计 | 展示当前队列数量、已确认数量、已驳回数量和本次处理数量。 | 已实现 |
| 驳回修正入口 | 在已驳回队列中提供 YOLO/LLM 再标注修正入口。 | 已实现 |

| 功能项 | 功能说明 | 当前状态 |
| --- | --- | --- |
| 可训练样本统计 | 统计已确认、自动通过、自动修正、无目标等可进入训练的数据。 | 已实现 |
| 训练/验证集划分 | 支持按比例划分训练集和验证集。 | 已实现 |
