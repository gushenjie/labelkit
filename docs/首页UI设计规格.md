# LabelKit 首页 UI 设计规格

> 供 UI 设计师使用的首页内容元素清单。  
> 首页定位：**项目工作台入口**（内部 B 端工具），不是对外营销落地页。
>
> 本文记录首页业务内容范围；颜色、排版、组件和交互实现以 [`UI设计规范.md`](./UI设计规范.md) 为准。

---

## 一、产品定位（背景）

**LabelKit** 是内部使用的 **YOLO 标注训练平台**。

核心流程：

> 建项目 → 传视频/图片 → 抽帧去重 → LLM 自动标注 → 人工复查 → 训练模型 → 模型反哺

首页角色：用户打开应用后第一眼看到的地方，用来**浏览、创建、进入各项目**。

---

## 二、页面整体结构（含全局壳）

首页不是孤立一页，外面有一层**全局导航壳**，设计时需一并考虑：

| 区域 | 内容 | 说明 |
|------|------|------|
| 顶栏 Logo | `LabelKit` | 点击回首页 |
| 顶栏导航 | `项目`（当前页）、`设置` | 仅 2 个入口，无用户头像/登录 |
| 主内容区 | 首页正文 | 最大宽度约 1280px，左右留白 |

**设计风格参考**：偏 **B 端工具 / 数据标注平台**，不是 C 端消费产品。用户会长时间盯着屏幕做标注复查，需要**清晰、低干扰、信息密度适中**。

---

## 三、首页必须有的内容元素

### 1. 页面标题区（Page Header）

| 元素 | 文案/数据 | 交互 |
|------|-----------|------|
| 主标题 | 「项目」或「我的项目」 | — |
| 副标题/说明 | 一句话说明产品价值，例如：「以项目为单位管理素材、标注与训练」 | — |
| 主操作按钮 | 「新建项目」 | 跳转 `/projects/new` |

### 2. 项目列表（核心内容）

每个项目是一张**可点击卡片**，点击进入 `/projects/{id}`（项目工作台）。

**卡片上必须展示的数据**（后端已有）：

| 字段 | 含义 | 展示建议 |
|------|------|----------|
| `name` | 项目名称 | 主视觉，1 行，过长省略 |
| `task_type` | `detect` / `classify` | 标签：「目标检测」/「图像分类」 |
| `description` | 项目描述 | 最多 2 行，空则显示「无描述」 |
| `frame_count` | 帧数量 | 如「1,234 帧」 |
| `video_count` | 视频数量 | 如「12 视频」 |
| `disk_usage_mb` | 磁盘占用 | 如「856 MB」 |
| `updated_at` | 最后更新时间 | 建议展示，便于找最近活跃项目 |

**卡片交互**：

- 整卡可点击
- Hover 有明确反馈（边框/阴影/背景变化）
- 可选：卡片右上角「⋯」菜单 → 删除项目（当前无，可预留）

### 3. 空状态（0 个项目时）

| 元素 | 说明 |
|------|------|
| 插图/图标 | 表达「还没有项目」 |
| 引导文案 | 如「还没有项目，创建第一个开始标注」 |
| 主按钮 | 「新建项目」 |
| 可选辅助说明 | 简述流程：上传素材 → 自动标注 → 复查 → 训练 |

### 4. 加载状态

- 骨架屏或 loading，避免空白页

### 5. 错误状态（可选但建议）

- API 失败时：提示 +「重试」按钮

## 四、建议增加的内容（提升体验，非硬性）

这些**后端目前首页没直接给**，但可以设计占位，或后续加接口：

### A. 全局状态提示条（顶栏下方或标题区下方）

| 场景 | 内容 |
|------|------|
| 未配置 API Key | 黄色提示：「请先在设置中配置 DashScope API Key」→ 跳转设置 |
| 有任务在跑 | 如「2 个项目有任务进行中」→ 可点进对应项目任务中心 |

### B. 汇总统计（标题区下方一行）

跨项目聚合，适合项目多时：

- 项目总数
- 总帧数
- 总磁盘占用
- 待复查帧数（需新接口）

### C. 列表工具栏

| 功能 | 说明 |
|------|------|
| 搜索 | 按项目名过滤 |
| 排序 | 最近更新 / 创建时间 / 名称 |
| 视图切换 | 卡片 / 列表（列表可显示更多字段） |
| 筛选 | 按任务类型（检测/分类） |

### D. 项目卡片增强信息（需后端扩展）

- 标注进度条：已标注 / 待复查 / 已完成 占比
- 最近活动：「3 小时前完成自动标注」
- 类别数量：如「5 个类别」
- 缩略图：最近一帧预览（视觉会好很多）

## 五、首页不要放的内容

避免和**项目内页**抢戏：

| 不要放 | 原因 |
|--------|------|
| 素材上传、抽帧、去重 | 在项目 → 素材管理 |
| 自动标注、复查画框 | 在项目 → 自动标注 / 复查 |
| 训练、模型版本 | 在项目 → 训练模型 |
| 全局设置表单 | 在 `/settings` |
| 大段产品介绍、定价 | 这是内部工具，不是官网 |

首页只做：**选项目 / 建项目 / 看全局概览**。

## 六、用户路径（设计时对照）

```
首页
 ├─ 点击「新建项目」→ 新建页（选 detect/classify、填名称描述类别）
 ├─ 点击项目卡片 → 项目工作台（7 个功能入口）
 │    ├─ 素材管理
 │    ├─ 自动标注
 │    ├─ 复查标注
 │    ├─ 训练模型
 │    ├─ 任务中心
 │    ├─ 模型试用
 │    └─ 项目设置
 └─ 顶栏「设置」→ 全局 API Key / VLM 配置
```

首页卡片点击后进入的**项目工作台**，也有固定模块（设计首页卡片时可参考层级关系）：

- 项目名 + 描述 + 类型
- 帧状态统计（unlabeled / llm_labeled / needs_human / human_ok 等）
- 7 个功能入口卡片

首页项目卡是**轻量预览**，项目内页是**完整工作台**。

---

## 七、需要设计师交付的稿

建议至少出这几张：

1. **有项目时** — 桌面端（≥1280px），含 3–6 张项目卡
2. **空状态** — 0 项目
3. **加载态** — 骨架屏
4. **可选** — 平板 / 手机（卡片 1 列）
5. **设计规范** — 颜色、字体、圆角、间距、标签样式（检测/分类两种类型要有区分）
6. **组件清单** — 顶栏、页面标题、主按钮、项目卡、空状态、标签 Badge

```json
{
  "name": "盖子检测-v2",
  "task_type": "detect",
  "description": "工业现场盖子开合状态检测，含 day/night 场景",

  "video_count": 18,

  "updated_at": "2026-07-02T15:30:00"
}
```

任务类型标签：

- `detect` → **目标检测**（建议偏蓝/青）
- `classify` → **图像分类**（建议偏紫/橙）

## 九、一句话总结

> 设计一个 **B 端 AI 标注平台的项目列表首页**：顶栏 + 标题区（含「新建项目」）+ 项目卡片网格；每张卡展示名称、任务类型、描述、帧/视频/容量、更新时间；支持空状态与加载态；风格专业、克制，信息清晰，不要做成营销落地页。

## 十、已确认的减法清单（2026-07-03）

首页按「只做选项目 / 建项目」瘦身，**以下元素已从实现中移除**：

| 已移除 | 原因 |
|--------|------|
| 顶栏通知、帮助、用户头像 | 无对应后端能力 |
| 「系统运行正常」状态芯片 | 装饰性，无实际信息 |
| 左侧快速筛选 + 我的视图 | 与工具栏重复 / 假功能 |
| 右侧最近活动、快捷入口、存储圆环图 | 与顶栏导航重复或信息冗余 |
| 列表/卡片切换、分页 | 项目规模小，卡片网格即可 |
| 收藏星标、缩略图、项目状态标签 | 无持久化或易误导 |
| 标签组筛选 | 语义混淆，价值低 |

**当前保留**：标题区、新建项目、API Key 提示（未配置时）、一行汇总、搜索 + 类型 + 排序、项目卡片（含标注进度）、删除、空/加载/错误态。
